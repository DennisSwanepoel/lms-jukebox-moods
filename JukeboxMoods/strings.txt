PLUGIN_JUKEBOXMOODS_MOODS
	EN	Moods

PLUGIN_JUKEBOXMOODS_MOODS_DESC
	EN	Each mood is a set of rules that decides which tracks can be picked, using the fields LMS already knows plus your own file tags if Additional file tags is switched on. "When this mood runs dry" decides what happens once all its tracks have played. A mood name switches to that mood. Don't Stop the Music goes back to the mood you picked in My Apps and keeps playing it, with repeats if needed, so the music never stops. Restart Current Mood replays the mood that is playing, allowing repeats. Song Mix plays random tracks from your whole library. Do Nothing adds nothing more, so playback stops when the queue ends.

PLUGIN_JUKEBOXMOODS_TOPUP
	EN	Tracks per top-up

PLUGIN_JUKEBOXMOODS_TOPUP_DESC
	EN	How many tracks to add each time Don't Stop The Music asks for more. LMS asks whenever fewer than two tracks are lined up after the one it is loading, so you will usually see two or three upcoming tracks. Fewer tracks per top-up means mood switches take effect sooner.

PLUGIN_JUKEBOXMOODS_REPEAT

PLUGIN_JUKEBOXMOODS_REPEAT_DESC

PLUGIN_JUKEBOXMOODS_FILETAGS
	EN	Additional file tags

PLUGIN_JUKEBOXMOODS_FILETAGS_DESC
	EN	Off: mood rules can use the fields LMS already stores, such as artist, genre, year and rating. On: after each library scan the plugin also reads every extra tag it finds in your music files (for example MOOD, ENERGY or GROUPING) and adds them to every mood's rule list under File tags. The first scan of a large library can take several minutes; reload this page when it has finished. For tags holding several values, such as "Chilled;Summer", use the "contains" rule.

PLUGIN_JUKEBOXMOODS_EVENTS
	EN	Events

PLUGIN_JUKEBOXMOODS_EVENTS_DESC
	EN	An event plans a sequence of moods, for example Chilled for 120 minutes, then Braai for 60, then Party until stopped. Start it manually from My Apps > Jukebox Moods, or let it start at a date and time. While it runs, all mood rules, fallbacks and guest requests work as normal; the event only changes the mood when each slot's time is up. Picking a mood by hand plays until the next slot change. "When the event ends" decides what follows the last slot, and "Change moods" whether the current song finishes first or a mood track is skipped straight away (guest requests are never cut).
