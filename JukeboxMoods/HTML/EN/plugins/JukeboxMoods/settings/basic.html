[% IF jm_activePlayers %] Active on: [% jm_activePlayers | html %]. [% ELSIF jm_playerCount %] Not switched on for any player yet - see step 3. [% ELSE %] No player is connected to LMS yet - start a player first. [% END %] Show setup steps
  1. Optional - your own file tags. To build moods on tags such as MOOD, ENERGY or GROUPING, tick Scan additional tags from my music files below, save, and reload this page when the scan has finished.
  2. Create a mood. Click Add mood, add one or more rules, check them with Count matching tracks, choose what happens when the mood runs dry, then click Save Settings.
  3. Switch it on for each player. In Material: open the player menu, choose Player settings, then Don't Stop The Music. In the classic web interface: Settings > Player, choose the player, then the Don't Stop The Music page. Select Jukebox Moods (active mood) and make sure the player's repeat is off. [% IF jm_inactivePlayers %]
    Not yet switched on: [% jm_inactivePlayers | html %].[% END %]
  4. Optional - events. Under Events, plan a sequence of moods; start it from My Apps > Jukebox Moods or let it start at a set time.
  5. Choose a mood. Open My Apps > Jukebox Moods and pick a mood. From then on, whenever the queue runs out, tracks from the active mood are added automatically. You can still add or change tracks yourself at any time.
